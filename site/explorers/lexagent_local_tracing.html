Keep your LexAgent traces on your own machine

Switching from LangSmith to local tracing takes two changes: stop sending spans to LangSmith, and point them at something that stores data locally. Pick one of three routes, depending on whether you want a trace viewer or only files.

Running in Colab? There, "local" means the Colab VM, which is wiped when the session ends. To keep traces on your own computer, run the notebook in Jupyter on your laptop, or download the trace files before the session closes.

Option 1

Arize Phoenix

Phoenix has a span tree, token counts, latency, and inputs and outputs, much like LangSmith. It is built on OpenTelemetry, so it also handles the notebook's two processes.

  1. Install and start the viewer

    Run this in a terminal, or prefix each line with ! in a notebook cell.

    terminal
    pip install arize-phoenix openinference-instrumentation-langchain
phoenix serve        # UI at http://localhost:6006

  2. Turn LangSmith off and Phoenix on

    In Section 2, replace the LANGSMITH_* block with this.

    notebook · Section 2
    os.environ["LANGSMITH_TRACING"] = "false"     # @traceable becomes a no-op
os.environ["LANGCHAIN_TRACING_V2"] = "false"

from phoenix.otel import register
from openinference.instrumentation.langchain import LangChainInstrumentor

tracer_provider = register(
    project_name="lexagent-rental-law",
    endpoint="http://localhost:6006/v1/traces",
)
LangChainInstrumentor().instrument(tracer_provider=tracer_provider)

    Also delete the LangSmithClient() connection check, and the ls_client.get_run_url call inside _trace_url.

  3. Instrument the MCP server too

    Add the same lines to the top of legal_mcp_server.py. That captures the nested ChatOpenAI call inside rewrite_legal_clause.

With only these steps, every LLM call, tool call and LangGraph node is recorded with tokens and latency, and nothing leaves your machine.

Option 1, continued

Keep your custom spans and metadata

Once LangSmith is off, two things stop working:

  • The @traceable spans and the metadata they write, such as outcome, route, tool_status, scope and repair.
  • The langsmith-trace header that links the notebook to the server.

Both have direct OpenTelemetry equivalents. The idea stays the same; only the header name and the library change.

LangSmithOpenTelemetry @traceable(name=...)→tracer.start_as_current_span(...) run.metadata["outcome"] = ...→span.set_attribute("outcome", ...) run.to_headers()→propagate.inject(carrier) langsmith-trace header→traceparent header tracing_context(parent=...)→propagate.extract(headers)
notebook · a span with metadata
from opentelemetry import trace
tracer = trace.get_tracer("lexagent")

def agent_node(state):
    with tracer.start_as_current_span("agent_node") as span:
        span.set_attribute("step_count", step_count)
        ...
        span.set_attribute("outcome", "tool_call")
notebook · tools_node sends the trace context
from opentelemetry.propagate import inject

carrier = {}
inject(carrier)        # adds the current span's "traceparent" header
connection = mcp_client.connections["lexagent_tools"]
connection["headers"] = {**(connection.get("headers") or {}), **carrier}
legal_mcp_server.py · the server picks it up
from opentelemetry.propagate import extract

def _otel_parent(ctx):
    try:
        return extract(dict(ctx.request_context.request.headers))
    except Exception:
        return None     # tracing must never break a tool

@mcp.tool()
def policy_search_tool(query: str, ctx: Context = None) -> str:
    with tracer.start_as_current_span("policy_search_tool",
                                      context=_otel_parent(ctx)) as span:
        span.set_attribute("tool", "policy_search_tool")
        return _policy_search(query)
Teaching point. Moving from a vendor SDK to an open standard leaves the instrumentation pattern intact. Students who understand the LangSmith version already understand this one.
Option 2

Plain JSON files, no viewer

If you only need a record on disk, a small LangChain callback handler writes each completed run tree to a JSON Lines file.

notebook · new cell
from langchain_core.tracers.base import BaseTracer

class JsonlTracer(BaseTracer):
    def __init__(self, path="lexagent_traces.jsonl"):
        super().__init__()
        self.path = path

    def _persist_run(self, run):
        # Called once per root run, with all children in run.child_runs
        with open(self.path, "a") as f:
            f.write(json.dumps(run.dict(), default=str) + "\n")

Pass it in the astream config in both run_legal_agent and run_and_capture:

notebook · Sections 7.5 and 14.1
config={"callbacks": [JsonlTracer()], "metadata": {"query_id": query_id}, ...}

It needs no extra installs, and each line is a full run tree. It has two limits:

  • It only sees LangChain and LangGraph runs. Your @traceable metadata and the server-side spans are not captured.
  • There is no UI for browsing the trees.
Option 3

Self-host LangSmith

LangSmith can run on your own infrastructure with Docker or Kubernetes. Your existing code would work unchanged: you would only point LANGSMITH_ENDPOINT at your own server. Self-hosting requires an Enterprise license, so it's rarely practical for a course or a personal setup.
